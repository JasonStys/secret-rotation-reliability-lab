# Security policy

Created by Jason Stys. This defensive lab is not a production secrets manager. Use only fictional data on an acknowledged disposable host. Never submit tokens, private keys, unseal material, resume/user data or raw ignored logs in an issue. For suspected security bugs, use GitHub private vulnerability reporting where enabled or contact Jason through the linked public profile to arrange a private channel; do not publish exploit details before coordination. No response SLA or paid support is promised.

Review [threat model](docs/threat-model.md) and [runbook](docs/runbook.md) before running the live exercise. Fixed loopback/trust, conservative expiry, ownership checks and no artifact uploads are mandatory controls. Findings must be corrected, not suppressed. This repo does not authorize accessing another person's hosts/accounts or scanning outside the owned fixture.
